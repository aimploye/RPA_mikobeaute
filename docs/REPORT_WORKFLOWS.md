# SPA-POS 報表任務規格

## 全域規則

- 所有任務都要上傳 Google Drive。
- 每個輸出檔案都有自己的 `drive_folder_id` 或 `drive_folder_url`。
- 輸出副檔名預設 `.xls`。
- 日期格式用 POS 畫面格式：`yyyy/MM/dd`。
- 報表入口都在 `統計報表`。
- 報表選單文字以畫面實際文字為準：
  - 商品銷售明細 → `商品銷售明細表`
  - 課程服務明細 → `課程服務明細表`
  - 會員剩餘點數殘值統計表 → `會員剩餘點數殘值統計表`
  - 預約紀錄表 → `預約紀錄查詢統計表`
  - 客戶來源與產值報表 → `客戶來源與產值統計表`

## 日期變數

| 變數 | 說明 |
|---|---|
| `{today}` | 今天 |
| `{yesterday}` | 昨天 |
| `{month_start}` | 當月 1 號 |
| `{fixed:2024-01-01}` | 固定 2024/01/01 |

## R01 每日課程服務明細表 新+舊客

- 選單：`統計報表 > 課程服務明細表`
- 分店：所有分店
- 日期：當月 1 號到昨天
- 勾選：顯示銷售分店
- 取消勾選：不列明細
- 動作：檢視報表 → 等待報表 → 存檔 Excel
- 輸出：`R01_每日課程服務明細表_新舊客_{start}_{end}.xls`
- Drive：使用者在 GUI 填寫

## R02 每日商品銷售明細表 新+舊客

- 選單：`統計報表 > 商品銷售明細表`
- 分店：所有分店
- 日期：當月 1 號到昨天
- 勾選：
  - 顯示銷售分店
  - 顯示客代與電話
  - 顯示退費
- 取消勾選：不列明細
- 動作：檢視報表 → 等待報表 → 存檔 Excel
- 輸出：`R02_每日商品銷售明細表_新舊客_{start}_{end}.xls`

## R03 每日商品銷售明細表 僅新客

- 基礎同 R02
- 額外勾選：僅含新客
- 輸出：`R03_每日商品銷售明細表_僅新客_{start}_{end}.xls`

## R04 每日商品銷售明細表 僅新客二次篩選

- 基礎同 R02
- 動作：按其他條件 → 勾選二次篩選
- 輸出：`R04_每日商品銷售明細表_二次篩選_{start}_{end}.xls`

## R06 每週會員剩餘點數殘值統計表

- 選單：`統計報表 > 會員剩餘點數殘值統計表`
- 分店：逐分館，每間產出一份
- 日期：2024/01/01 到昨天
- 勾選：清單顯示
- 動作：檢視報表 → 等待報表 → 存檔 Excel
- 輸出：`R06_{branch_code}_會員剩餘點數殘值統計表_{end}.xls`
- Drive：每個分館可設定不同 folder ID

## R07 每日預約 截至前一日

- 選單：`統計報表 > 預約紀錄查詢統計表`
- 分館：顯示分館；依實機確認是多選或逐分館
- 日期：昨天到昨天
- 動作：檢視報表 → 存檔 Excel
- 輸出：`R07_每日預約_截至前一日_{yesterday}.xls`
