# 00 Start Here

- AGENTS.md
- docs/PROJECT_SPEC.md
- docs/ARCHITECTURE.md
- docs/REPORT_WORKFLOWS.md

請使用 `$using-agent-skills` 判斷本任務應用哪些 skills。若可用，請使用 `$spec-driven-development` 與 `$planning-and-task-breakdown`。

限制：

- 不得宣稱已完成 POS 實機操作。
- 不得硬寫滑鼠座標。
- 不得把密碼、token、Drive OAuth 寫進 repo。
- 第一階段只做無 POS 本機可測的 MVP-0.1。

請先回覆：

1. 你理解的專案範圍。
2. 你要建立的目錄與檔案。
3. 你會先做哪 5 個最小垂直切片。
4. 你會如何驗證每個切片。
